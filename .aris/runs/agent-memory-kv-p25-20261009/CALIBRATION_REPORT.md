Bootstrap是会话配对的经验分布10000次重采样；零观测差异得到零上界不能证明总体等价。输入均用于参数校准，正式质量门槛须独立seed和会话，且禁止在评估集调参。

性能是串行c1、配置间轮换GPU0–3的描述统计；不同配置只跑一个物理GPU，非均衡重复控制。少量数值微检查/短模型gate在其他GPU上开展，非prefix后段校准可能共享主机资源；这些数据不支持精确因果速度声明。GPU-ms、普通请求搬运量、峰值HBM缺失保持null；CUPTI诊断单独报告。
